# Война и Медицина: Интерактивная Визуализация

Проект о роли медицинской службы в Великой Отечественной войне.

## 🚀 Запуск сервера

### Способ 1: Node.js (рекомендуемый)
```bash
# Запуск сервера
node server.js

# Или через batch файл
start-server.bat
```

### Способ 2: Python
```bash
python -m http.server 8000
```

## 🌐 Доступ к сайту

После запуска сервера откройте в браузере:
- http://localhost:8000/

## 📊 Функционал

- **Интерактивные графики** по видам потерь
- **Carousel навигация** с стрелками и индикаторами
- **Адаптивный дизайн** для всех устройств
- **Динамика по годам** войны (1941-1945)

## 🎯 Виды графиков

1. Убито и умерло на этапах санитарной эвакуации
2. Пропало без вести, попало в плен
3. Небоевые потери
4. Ранено, контужено, обожжено
5. Заболело
6. Обморожено

## 🛠 Технологии

- HTML5, CSS3, JavaScript
- Node.js сервер
- Адаптивный дизайн
